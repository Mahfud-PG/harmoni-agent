# Harmoni Agent

**Harmoni Agent** adalah asisten AI pribadi yang berjalan di komputer Windows Anda secara mandiri. Aplikasi ini dirancang ramah bagi pengguna pembaca layar (screen reader NVDA / JAWS) dan terintegrasi dengan berbagai platform perpesanan serta sistem otomasi desktop.

---

## Fitur Utama

- **100% Aksesibel:** Seluruh antarmuka dapat dinavigasi dengan tombol `Tab` dan setiap tombol memiliki teks serta deskripsi yang jelas untuk screen reader.
- **Konektivitas Fleksibel:** Mendukung integrasi dengan berbagai penyedia AI (DeepSeek, Google Gemini, OpenAI, Groq, OpenRouter).
- **Multi-Platform Bridge:** Integrasi gateway lokal untuk Telegram listener dan WhatsApp Baileys multi-sesi.
- **Manajemen Berkas & Otomasi:** Dilengkapi dengan sinkronisasi Google Drive, YouTube uploader, automasi task scheduler, dan pelacakan pekerjaan.
- **Portabel & Terisolasi:** Berjalan di latar belakang Windows tanpa memerlukan instalasi manual dependensi sistem.

---

## Persyaratan Sistem

- **Sistem Operasi:** Windows 10 atau Windows 11 (64-bit).
- **Ruang Penyimpanan:** Sekitar 2 GB ruang kosong.
- **Kunci API:** Diperlukan salah satu API Key penyedia AI (DeepSeek, Gemini, OpenAI, dll.).

---

## Unduhan & Pemasangan

Unduh paket installer resmi **`HarmoniAgent_Setup_1.0.0.exe`** dari menu [Releases](https://github.com/Mahfud-PG/harmoni-agent/releases) dan ikuti panduan pemasangan pada layar.
